# Contexto sob demanda

## Antes e durante o trabalho

1. Defina o objetivo, a entrega e o critério de conclusão a partir do pedido ou ticket.
2. Parta do `AGENTS.md` e escolha somente os documentos indicados para essa tarefa.
3. Busque nomes, símbolos, caminhos e trechos relevantes antes de ler arquivos inteiros.
4. Amplie a leitura apenas quando uma dúvida ou dependência concreta exigir. Um link é uma referência, não uma obrigação de abrir.
5. Separe fatos verificados, decisões aprovadas, hipóteses e dúvidas. Cite caminhos, issues ou commits que sustentem o resultado.

Não carregue o repositório inteiro, todos os links, todos os tickets ou todos os documentos de domínio por precaução.

## Resumo e passagem de trabalho

Antes de trocar de sessão ou delegar uma parte, prepare um resumo curto com:

- Objetivo e estado atual.
- Decisões confirmadas e restrições relevantes.
- Arquivos alterados e evidências, incluindo verificações executadas e resultados.
- Pendências, bloqueios e próximo passo concreto.
- Poucos links ou caminhos para consulta direcionada.

Preserve detalhes na fonte original; não copie documentos inteiros para o resumo. Não apresente testes não executados ou relações não verificadas como concluídos.
