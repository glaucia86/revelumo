# Cobre

Palette selected in the Revelumo V3 comparison on 2026-10-12. `cobre-tokens.css` is the exact token sheet normalized and validated through the locally installed OpenDesign importer (snapshot `0bd8251c9b5c0bed4b3aef87f53f9c1eadc493c7`). React composition and scoped CSS are manually authored; no model/API generated the product UI.

The 56-token compatibility contract includes unused fallback tokens. Only styles for the catalog and shared shell consume this theme in issue #29. Existing editor controls remain the subject of #31. No mock catalog, remote images, CSS brightness rendering or fixed photo count is included.

Geist Latin variable font: The Geist Project Authors, SIL Open Font License 1.1, preserved in `public/licenses/Geist-OFL.txt` (copied into the packaged renderer by Vite). Local distribution; no CDN request. Source: https://github.com/vercel/geist-font . The catalog's simple outline SVGs and optical mark are locally authored.
